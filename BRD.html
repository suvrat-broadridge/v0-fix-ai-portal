Executive Summary

B-COMET is a revolutionary platform designed to streamline and accelerate FIX connectivity onboarding for financial institutions. By automating configuration management, monitoring, evaluation, and tracking, B-COMET reduces onboarding time by up to 60% and improves client experience significantly.

The platform combines industry-leading FIX expertise with modern automation and AI capabilities to deliver a best-in-class onboarding experience that competitors cannot match.

User Flows & Processes

1. Onboarding Case Creation Flow

The structured workflow guides users through creating and managing new onboarding cases:

Step 1: Case Information - Enter client details, legal entity, and contact information
Step 2: Asset Classes & Specs - Select asset classes and choose FIX versions
Step 3: Configuration - Set connectivity environment, venues, and certification window
Step 4: Team Assignment - Assign onboarding manager, tech lead, QA lead, and business approver
Step 5: Blockers & Review - Identify critical path blockers and review before launch

2. Case Detail View

Once created, users access the detailed case view to:

  • Monitor case progress through stages (Setup → Testing → Certification → Deployment → Production)
  • Track gate approvals (Gate A, Gate B, Gate C)
  • View readiness scores and SLA dates
  • Manage critical blockers and dependencies
  • Access related artifacts and documentation

3. Approval & Evidence Management

Multi-level approval process with evidence tracking:

  • Submit evidence and artifacts for review
  • Receive approvals from required stakeholders
  • View approval history and feedback
  • Track compliance with regulatory requirements

4. Tool Access & Utilization

Users access specialized tools directly from the platform:

  • FIX Message Creator - Build and validate FIX messages
  • Specification Compare - Compare client vs. internal FIX specs
  • ATDL Validator - Validate ATDL configurations
  • Test Case Generator - AI-generated test scenarios
  • Certification Engine - Run certification tests and generate reports

Key Use Cases

Use Case 1: New Client Onboarding (Institutional)

A large institutional client (e.g., major hedge fund) needs to connect to multiple FIX venues. B-COMET reduces the typical 16-week process to 6-8 weeks by automating configuration management, test generation, and certification.

Use Case 2: Multi-Asset Class Migration

An existing client wants to expand from equities to derivatives. B-COMET identifies specification differences, generates new test scenarios, and manages the certification process for the new asset class in parallel.

Use Case 3: Production Configuration & Monitoring

After go-live, B-COMET monitors production connectivity, validates order flow, detects anomalies, and provides real-time alerts for any configuration issues.

Use Case 4: SLA Management & Escalation

The platform automatically tracks SLAs by stage and owner, sends notifications when thresholds are approaching, and escalates blockers to leadership for resolution.
